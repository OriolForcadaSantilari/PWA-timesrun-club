# TimesRun Club

Find people to run with in Barcelona.

**[timesrun.club](https://timesrun.club)**

## What it does
- Create a run on a public meeting pin on the map, with your own pace
- Browse runs created by other people and join in one tap
- Clubs, user profiles and sign-in
- Spanish and English
- Installable on your phone as a progressive web app (PWA)

## Built with
`Next.js` `React` `TypeScript` `Tailwind CSS` `Convex` (database, backend and auth) `Leaflet` (maps) `Vercel`

I started it from a personal need: going for a run with other people without having to join a formal club. Designed and built by me with AI-assisted development (Cursor, Claude Code).

## Run it locally
```bash
npm install
npx convex dev   # backend
npm run dev      # web app on http://localhost:3000
```
